# skill_batch_capacity

## 技能名称
skill_batch_capacity - 医疗净化工程检验批容量清单生成器

## 技能功能
- 读取并解析图纸内容（PDF、图片、CAD文件）
- 提取每张图纸的材料信息（名称、型号、数量）
- 提取图纸图号和图纸名称
- 根据检验批项目生成对应检验批容量清单
- 输出结构化的容量清单报告

## 技能应用场景
- 医疗净化工程材料统计
- 检验批容量计算
- 工程材料管理
- 施工进度跟踪

## 技能依赖
- Python 3.8+
- 核心库：os, re, json, argparse, datetime
- 可选依赖（实际应用中需要）：
  - OpenCV (图像处理)
  - PyPDF2 (PDF处理)
  - Tesseract OCR (文字识别)

## 安装方法
1. 将技能目录复制到 WorkBuddy 技能目录：
   ```bash
   cp -R skill_batch_capacity ~/.workbuddy/skills/
   ```

2. 安装依赖（实际应用中需要）：
   ```bash
   pip install opencv-python pypdf2 pytesseract
   ```

## 使用方法

### 命令行使用
```bash
# 基本使用（解析所有图纸，生成全部检验批容量）
python scripts/batch_capacity.py --files drawing1.pdf drawing2.jpg

# 指定检验批项目
python scripts/batch_capacity.py --files drawing1.pdf --inspection-items "风管安装" "防火阀安装"

# 指定输出格式
python scripts/batch_capacity.py --files drawing1.pdf --output-format json
```

### WorkBuddy 中使用
1. 在 WorkBuddy 中输入命令：
   ```
   /batch-capacity
   图纸文件: [上传图纸文件]
   检验批项目: 风管安装, 防火阀安装
   ```

2. 技能会自动解析图纸并生成检验批容量清单

## 支持的文件格式
- PDF 文件 (.pdf)
- 图片文件 (.jpg, .jpeg, .png, .bmp)
- CAD 文件 (.dwg, .dxf)

## 输出格式
- Markdown (.md) - 默认格式
- JSON (.json) - 便于程序处理
- 纯文本 (.txt) - 简单文本格式

## 技能限制
- **模拟数据**：当前版本使用模拟数据，实际应用需要集成真实的OCR和图纸解析功能
- **材料识别**：依赖图纸清晰度和标准化程度
- **处理时间**：视图纸复杂度而定
- **单位换算**：当前版本不支持复杂的单位换算
