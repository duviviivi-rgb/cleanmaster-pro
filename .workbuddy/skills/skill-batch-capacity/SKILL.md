## 技能名称
skill-batch-capacity

## 技能描述
读取图纸内容，提取材料信息，生成医疗净化工程检验批容量清单

## 技能标签
医疗净化工程, 检验批, 材料清单, 图纸解析, 工程管理

## 技能版本
1.0.0

## 技能作者
OpenClaw

## 技能分类
工程管理

## 技能触发
- 命令: /batch-capacity
- 描述: 生成检验批容量清单

## 技能参数
- 图纸文件: 上传的图纸文件
- 检验批项目: 需要生成容量清单的检验批项目

## 技能功能
1. 读取并解析图纸内容
2. 提取每张图纸的材料信息（名称、型号、数量）
3. 提取图纸图号和图纸名称
4. 根据检验批项目生成对应检验批容量清单
5. 输出结构化的容量清单报告

## 技能应用场景
- 医疗净化工程材料统计
- 检验批容量计算
- 工程材料管理
- 施工进度跟踪

## 技能限制
- 支持的图纸格式: PDF, CAD, 图片
- 处理时间: 视图纸复杂度而定
- 材料识别: 依赖图纸清晰度和标准化程度

## 技能依赖
- Python 3.8+
- ezdxf (CAD文件处理)
- OpenCV (图像处理)
- PyPDF2 (PDF处理)
- Tesseract OCR (文字识别)

## 技能使用指南

### 在 WorkBuddy 中使用
1. **触发技能**：在 WorkBuddy 聊天窗口中输入 `/batch-capacity`
2. **上传图纸**：在弹出的对话框中上传图纸文件或目录
3. **指定参数**：
   - 图纸文件：选择要分析的图纸文件或目录
   - 检验批项目：可选，指定需要重点分析的检验批项目
4. **等待处理**：技能会自动处理图纸并生成报告
5. **查看结果**：技能会返回生成的检验批容量和隐蔽工程报告

### 输入示例
```
/batch-capacity
图纸文件: C:\Users\vivia\Desktop\东方肝胆医院医疗净化工程交付资料V4\图纸
检验批项目: 风管安装, 给排水管道安装
```

### 常见问题解决
1. **无法触发技能**：确保输入正确的命令 `/batch-capacity`
2. **文件上传失败**：确保文件格式正确（支持 DWG、DXF、PDF、图片）
3. **分析结果不准确**：尝试使用 DXF 格式的图纸，或确保图纸清晰可读
4. **处理时间过长**：对于大型图纸，处理时间可能较长，请耐心等待
5. **报告格式问题**：技能会自动生成 Markdown 格式的报告，可直接查看或保存为文件
